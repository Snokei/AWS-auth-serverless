# AWS & Node.js Assessment Questions

## Question 1: Serverless Authentication
Design and implement a serverless application using AWS Lambda and DynamoDB that handles user authentication and authorization. The application should include functionality for user registration, login, and token-based authentication. Provide the code for the Lambda function and explain how you would configure DynamoDB to store user data securely.

## Question 2: React.js Frontend with Lambda Backend
Create a React.js application that interacts with a Node.js backend API hosted on AWS Lambda. The application should display a list of items retrieved from a DynamoDB table and allow users to add, update, and delete items. Provide the code for both the React.js frontend and the Node.js Lambda function, and explain how you would handle API rate limits and error handling.

## Question 3: Optimization and Cold Starts
Optimize a Node.js application running on AWS Lambda that interacts with DynamoDB. The application currently experiences performance bottlenecks due to inefficient queries and high cold start times. Explain how you would identify and resolve these issues, including specific changes to the Lambda function code and DynamoDB query pattern.

## Question 4: Real-time Notifications
Implement a real-time notification system using React.js, Node.js, AWS Lambda, and DynamoDB. The system should allow users to subscribe to specific events and receive notifications in real-time when those events occur. Provide the code for the Lambda function and React.js components, and explain how you would ensure scalability and low latency.

## Question 5: Batch Processing Microservice
Develop a Node.js microservice hosted on AWS Lambda that processes large datasets stored in DynamoDB. The microservice should include functionality for batch processing and parallel execution to handle millions of records efficiently. Provide the code for the Lambda function and explain how you would configure DynamoDB and Lambda to optimize performance and minimize costs.
